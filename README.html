Project Overview

AquaDose is a local-network aquarium dosing system. It uses an ESP32 to switch calibrated peristaltic pumps through MOSFET driver circuits, then exposes control through both a browser-based web interface and a native Android app.

The project solves a practical aquarium maintenance problem: small, repeatable doses of additives are hard to do manually with consistency. AquaDose stores pump calibration rates and daily schedules so each channel can dose a configured amount at a configured time.

ESP32 firmware
Wi-Fi setup, web UI, pump scheduler, NVS storage, HTTP API.
Android app
Local controller connection, dashboard, pump controls, calibration, schedules, settings.
Web interface
Browser UI served directly by the ESP32 at its local IP address.
Peristaltic pumps
Up to 8 dosing channels, switched through external drivers.

Architecture Flow

Android app or web browser
-> ESP32 HTTP endpoints: /status, /savePump, /manual, /primeStart, /calRun, /calSave, /saveTZ, /stop, /reset, /factoryReset
-> Firmware scheduler and pump runner
-> ESP32 GPIO pins
-> MOSFET driver circuits with flyback protection
-> Peristaltic pump channels

Hardware Requirements

  • ESP32 development board.
  • 1 to 8 peristaltic dosing pumps.
  • Logic-level N-MOSFET per pump channel.
  • 100Ω resistor per pump channel between ESP32 GPIO and MOSFET Gate.
  • 10kΩ resistor per pump channel, connected between MOSFET Gate and Source/GND.
  • Flyback diode per pump motor, with the striped cathode side on Pump + / +12V.
  • External pump power supply sized for the pump voltage and total current.
  • Shared common GND between ESP32 GND, buck GND, MOSFET sources, and 12V PSU negative.
  • Tubing, containers, and a gram scale for calibration with water.
MOSFET selection: Use a MOSFET that is fully enhanced at ESP32 logic level, 3.3V Vgs. Do not rely only on the threshold voltage from the datasheet. The MOSFET must have low Rds(on) at 2.5V or 3.3V gate drive, especially if the pump current is high.
Safety note: aquarium dosing errors can harm livestock. Test every channel with water, label every tube, calibrate before dosing additives, and start with small manual test doses.

Wiring Overview

The firmware defaults to 8 pump outputs. If fewer pumps are installed, use the first channels and reduce PUMP_COUNT in the firmware if desired. Each pump channel repeats the same low-side N-MOSFET block.

Pull-down resistor: The 10kΩ pull-down resistor keeps the MOSFET gate LOW while the ESP32 is booting, resetting, disconnected, or when the GPIO is floating. Without it, a pump may turn on unexpectedly.
Gate resistor: The 100Ω resistor is a series gate resistor. It limits transient current from the ESP32 GPIO into the MOSFET gate. It does not replace the pull-down resistor.
Power separation: the ESP32 GPIO controls the MOSFET gate only. The pump motor is powered by the external pump supply, not by the ESP32 pin. Do not power pump motors from ESP32 pins.
Common ground: Common GND means ESP32 GND, buck GND, MOSFET source, and 12V PSU negative must be connected together so the gate signal has the same reference as the driver.

Inductive pump motors need flyback protection. Connect the diode across the pump motor with the diode cathode / striped side to Pump + / +12V and the diode anode to Pump - / MOSFET Drain.

Open And Upload

  1. Install the ESP32 board package in Arduino IDE.
  2. Open source/arduino/AquaDose/AquaDose.ino.
  3. Select the matching ESP32 board and serial port.
  4. Confirm the pump pin array matches your wiring.
  5. Upload to the ESP32.
  6. Open Serial Monitor at 115200 baud for boot and status logs.

Wi-Fi Setup And Reset

On first boot, after Wi-Fi reset, or when saved Wi-Fi cannot connect, the firmware starts SoftAP setup mode. The AP SSID starts with AquaDose, the password is 12345678, and the setup address is http://192.168.4.1.

The source does not include a DNS captive portal library, so open the setup address manually in a browser after joining the AquaDose AP.

  • /reset clears Wi-Fi settings and reboots into setup mode while keeping pump configuration.
  • /factoryReset clears Wi-Fi, timezone, pump names, calibration rates, schedules, and schedule history.
  • Holding BOOT/GPIO0 during startup for about 5 seconds also triggers factory reset.

Calibration

Calibration runs a selected pump for 60 seconds. The user weighs the collected water in grams, and the firmware stores mlPerSec = grams / 60. Manual and scheduled dosing use that saved rate. Manual dose duration is capped by the firmware safety limit.

Android App Guide

The APK is at apk/AquaDose.apk. This release uses a debug APK because release signing is not configured in the project. Android source shows minSdk = 26, so the app supports Android 8.0 and newer.

adb install -r apk/AquaDose.apk

The app stores only the controller address locally on the phone. It communicates with the ESP32 over local HTTP.

The Android UI is adaptive. Compact-width screens use a single-column layout with bottom navigation. Medium and expanded widths use a navigation rail, and the Pumps screen becomes a list-detail workspace with pump cards on one side and the selected pump controls on the other.

Connect The Android App To The ESP32

  1. Power the ESP32 and make sure the phone is on the same local network.
  2. Open the app and enter the controller address, for example http://192.168.0.129.
  3. Use Use setup address for http://192.168.4.1 while the phone is connected to the AquaDose setup AP.
  4. Tap refresh after saving the address. The Dashboard should show Online, controller time, time validity, and pump running state.

Pump List And Pump Names

  • The Pumps screen lists all channels returned by /status, including pump number, saved pump name, GPIO pin, scheduled dosing permission, enabled schedule count, calibration state, and calibration rate.
  • On wider screens, the pump list and selected pump detail are shown side by side so pump status and actions remain visible without losing the list context.
  • Open a pump and edit Pump name in the Configuration section. Names are trimmed, must not be empty, and are limited to 31 characters to match the firmware storage field.
  • Tap Save pump settings. The app saves through the ESP32 /savePump endpoint, refreshes /status, and shows the confirmed name from the controller.

Calibration And Pump Actions

  • Calibration shows the current rate in ml/sec. The Configuration section can also save a direct calibration rate from 0 to 100 ml/sec through /savePump.
  • The 60 second calibration flow runs the pump, then saves measured grams through /calSave, where the firmware stores mlPerSec = grams / 60.
  • Uncalibrated pumps use the firmware's stored default rate of 0.0. This project does not define a 65 ml per 60 seconds fallback.
  • Manual dosing uses /manual after confirmation. Prime uses /primeStart after confirmation, and Stop Prime uses /primeStop.
  • Emergency Stop sends /stop after confirmation.

Scheduled Dosing

  • Scheduled dosing must be explicitly allowed per pump. The pump detail screen shows whether schedules are allowed or blocked.
  • Each pump has 8 daily schedule rows with enable state, hour, minute, and amount. Rows that have local edits are marked as unsaved until Save schedule succeeds and the app refreshes from the ESP32.
  • The Android app and firmware validate scheduled dose amounts from 0.1 to 999 ml before saving to the controller.
  • After saving schedules or schedule permission, the app waits for the ESP32 response, refreshes /status, and reloads the confirmed state from the controller.

Logs, Reconnect, And Reset Flows

  • Logs shows RAM-only controller logs returned from /status. Logs clear after controller reboot.
  • Settings supports saved controller address, timezone save, Wi-Fi reset, and factory reset.
  • Wi-Fi reset opens a confirmation before calling /reset. Factory reset requires two confirmations before calling /factoryReset.

Web Interface Guide

The web interface is served by the ESP32 firmware on port 80. During setup mode, join the AquaDose AP and open http://192.168.4.1. After the controller joins your Wi-Fi, open the controller IP shown in Serial Monitor or in your router.

Setup Page

When in setup mode, the root page displays a Wi-Fi SSID field, Wi-Fi password field, timezone select, and Save and Reboot. If the new credentials fail on first validation, the firmware returns to setup mode.

Installation Flow

  1. Flash the ESP32 firmware from source/arduino/AquaDose/AquaDose.ino.
  2. Connect your phone or computer to the AquaDose Wi-Fi setup AP.
  3. Open http://192.168.4.1, enter Wi-Fi credentials, select timezone, and save.
  4. Install the Android APK from apk/AquaDose.apk.
  5. Connect the app to the controller IP, or use the setup address while still on the setup AP.
  6. Open the pump list, confirm every GPIO mapping, and edit pump names if needed.
  7. Prime tubing with water.
  8. Calibrate every pump with the 60 second water test.
  9. Create schedule rows only after calibration. Enabled schedule doses must be between 0.1 and 999 ml.
  10. Test a small manual dose with water before dosing aquarium additives.

Safety And Limitations

  • Do not dose without calibration. The firmware rejects manual doses for pumps with rate below the calibration threshold.
  • Dose inputs accept 0.1 to 999 ml, but AquaDose cannot decide what is safe for the aquarium. Use conservative values and test with water first.
  • Do not exceed safe daily dosing amounts for the aquarium. AquaDose cannot know livestock tolerance.
  • Test pumps with water before fertilizer, trace elements, alkalinity, calcium, or other additives.
  • Wrong wiring can trigger the wrong pump, prevent pumps from running, or make pumps run together.
  • Use flyback diodes and a driver circuit. Do not connect a pump directly to an ESP32 GPIO pin.
  • Only one pump is intended to run at a time in the firmware run state.
  • Controller logs are stored in RAM and clear after reboot.
  • The APK in this release is debug signed, not production signed.

Troubleshooting

ProblemChecks
Phone cannot find deviceConfirm the phone is on the same Wi-Fi network as the ESP32, or join the AquaDose setup AP and use http://192.168.4.1.
ESP32 not connecting to Wi-FiUse Serial Monitor at 115200 baud. If credentials fail on first validation, firmware returns to setup AP mode. Re-enter SSID/password.
Pump does not runCheck external pump power, MOSFET wiring, shared ground, pump polarity, and that another pump is not already running.
Wrong pump runsCompare wiring against the GPIO table and the app pump cards. Correct either wiring or the PUMP_PINS array.
All pumps run togetherCheck MOSFET driver wiring, common ground, gate pulldowns if used, and accidental shorting between driver inputs.
Dose amount is inaccuratePrime the tube, rerun 60 second calibration with water, weigh accurately, and save calibration for the correct pump.
Pump name does not changeUse 1 to 31 non-blank characters, tap Save pump settings, then refresh. The app shows the name confirmed by /status.
Schedule does not saveCheck that enabled rows use hour 0-23, minute 0-59, and dose 0.1-999 ml.
Schedule does not triggerConfirm controller time is valid, timezone is correct, pump scheduled dosing is allowed, schedule row is enabled, pump is calibrated, and the controller is powered at the scheduled minute.
Factory reset does not return to setup flowWait for reboot, scan Wi-Fi for the AquaDose AP, or hold BOOT/GPIO0 during startup for about 5 seconds to trigger hardware factory reset.
APK install blocked by AndroidAllow installation from the file source or install with ADB using adb install -r apk/AquaDose.apk. The APK is debug signed.
